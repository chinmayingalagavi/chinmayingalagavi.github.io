# chinmayingalagavi.github.io

Website of Chinmay Ingalagavi. Based on the Minimal theme by orderedlist.

Edit `_data/navigation.yml` to control both the sidebar and the page sections:

- Reorder entries to move sections.
- Change `name` to rename a sidebar link and its section heading.
- Change `url` (for example, `#about-me`) to set the link and section anchor.
- `data_source` selects the file in `_data` without its `.yml` extension;
  `data_key` selects a text field within that file, when needed.

Sections with missing or empty content are hidden in both places. Text fields
support Markdown; publications, works in progress, and teaching retain their
section-specific formatting in `index.md`.
